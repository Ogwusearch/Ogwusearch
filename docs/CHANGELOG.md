
---

# IMPORTANT RULE

Do not create another major project until the existing project inventory has been audited.

The purpose of the audit is not to eliminate projects arbitrarily.

The purpose is to determine:

```text
What should continue?
What should be finished?
What should be combined?
What should be paused?
What should be archived?
What should become reusable infrastructure?
```
