## Project evidence

Project pages should progressively document:

1. Overview and problem
2. Objectives and scope
3. Personal contribution
4. Architecture and implementation
5. Technologies and tools
6. Testing and validation evidence
7. Challenges and decisions
8. Current status
9. Repository, demo and supporting resources

## Status vocabulary

Use status labels accurately:

- Completed: implemented and demonstrated.
- In development: actively being built.
- Prototype: a working or partial proof of concept.
- Research: investigation without a completed implementation.

Do not describe planned, untested or unverified functionality as completed.
