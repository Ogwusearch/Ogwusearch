# Okpe Emmanuel Ogwu — Personal Portfolio

Personal portfolio for software engineering, AI systems, electronics, energy engineering and technical projects.

**Professional brand:** OGWU SEARCH

## Technology

- React
- TypeScript
- Vite
- React Router
- CSS

## Development

Install dependencies using the package manager already established for this project, then run:

```bash
npm run dev
```

## Validation

```bash
npm run build
npm run lint
```

## Architecture

- `src/app/`: application entry composition and routing.
- `src/features/`: feature-oriented pages and components.
- `src/components/layout/`: shared site layout.
- `src/components/ui/`: reusable UI primitives.
- `src/data/`: typed portfolio content.
- `src/styles/`: global CSS and design tokens.
- `public/`: static public assets.
- `docs/`: architecture, content and design documentation.

See `docs/architecture.md` for the architecture and migration boundaries.

## Scope

This is a static portfolio application. The current architecture does not require a backend, database or CMS.
